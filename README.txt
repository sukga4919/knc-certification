[ 실제 인증 마크(로고) 넣는 방법 ]

이 "marks" 폴더는 index.html 과 같은 위치에 두세요.
아래 파일명 그대로, 각 인증기관에서 받은 실제 공식 로고 이미지를 저장하면
홈페이지 사업분야 카드에 자동으로 표시됩니다.
(파일이 없으면 임시 그림이 대신 보이며, 화면은 깨지지 않습니다.)

■ 국내인증
  kc.png       - 국내 KC인증
  energy.png   - 에너지효율등급
  higheff.png  - 고효율에너지기자재 인증
  safety.png   - 안전인증 및 안전확인(공급자적합성확인)

■ 해외인증
  ce.png       - CE (유럽)
  fcc.png      - FCC (미국)
  pse.png      - PSE (일본)
  ul.png       - UL (북미)
  ccc.png      - CCC (중국)

■ 기업(확인)인증
  iso.png      - ISO 9001·14001·45001
  ks.png       - KS인증
  mainbiz.png  - 메인비즈(MainBiz)
  innobiz.png  - 이노비즈(INNO-BIZ)
  venture.png  - 벤처기업 확인
  rnd.png      - 기업부설연구소·개발전담부서
  direct.png   - 직접생산확인

* 권장: 배경이 투명한 PNG, 가로/세로 300px 내외.
* png 대신 jpg/svg 로 넣고 싶으면, index.html 의 렌더링 부분에서
  확장자(.png)만 원하는 형식으로 바꾸면 됩니다.
* 공식 로고는 각 인증을 취득할 때 인증기관이 제공하는 사용 지침(로고 파일)에
  따라 사용하세요.
