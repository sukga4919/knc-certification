[ 로고를 바꾸고 싶을 때 ]
* 위 파일을 같은 이름으로 덮어쓰면 됩니다.
* PNG 로 넣고 싶으면 같은 이름의 .png 를 이 폴더에 두세요.
  (예: kc.png) — svg 가 없거나 실패하면 png 를 자동으로 씁니다.
  권장: 배경이 투명한 PNG, 가로/세로 300px 내외.

[ 마크 도안 출처 ]
* kc / safety  : 국가기술표준원 국가통합인증마크 도안(색상 PANTONE 288C)
* energy       : 한국에너지공단 에너지소비효율등급 라벨
* higheff      : 한국에너지공단 원본 이미지 그대로
                 (eep.energy.or.kr 의 pic_bs0021.gif 를 png 로 변환)
* ce / ccc / ul / fcc / ks : 각 제도의 공식 도안(벡터)
* pse          : 일본 전기용품안전법 특정전기용품 마름모 마크
* mainbiz      : 중소벤처기업부 메인비즈 공식 SVG 로고 그대로
                 (smes.go.kr/mainbiz 의 toplogo.svg)
* innobiz      : 이노비즈협회 공식 로고 그대로
                 (innobiz.net 의 images/common/logo.gif 를 png 로 변환, 123x48)
* iso          : ISO 로고(파란 지구본) 이미지.
                 참고 - ISO 는 "인증받은 기업"이 자사 제품/홍보물에 ISO 로고를
                 쓰는 것을 금지합니다. 규격번호(ISO 9001 등) 표기는 가능합니다.
* venture      : 벤처기업확인기관 로고 이미지 그대로 (580x374)
                 ※ 원본에 여백이 넓어 화면에서는 다른 마크보다 작게 보입니다.
                    여백을 잘라내면 더 크게 나옵니다.
* rnd / direct : 제품에 붙이는 공식 마크가 없는 확인·신고 제도라
                 브랜드 색상의 글자 배지로 표시합니다.

* 실제 취득한 인증의 공식 로고는 인증기관이 제공하는 사용 지침에 따라 쓰세요.
